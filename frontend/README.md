
# Module 1 — User Interface

## Multimodal Deepfake & AI-Generated Content Detector

This folder contains the React-based frontend for the
Multimodal Deepfake & AI-Generated Content Detector.

The frontend allows users to upload images, videos, and
audio files, preview their content, submit them for analysis,
and view classification results.

## Technology Stack

- React
- JavaScript
- Vite
- Tailwind CSS
- Fetch API
- HTML5
- Git and GitHub

## Implemented Features

- Responsive dark-themed interface
- Drag-and-drop media upload
- File selection using the file browser
- Image, video, and audio preview
- Client-side file format and size validation
- Removal and replacement of uploaded files
- Analysis loading state
- Analysis cancellation
- Error handling and retry functionality
- Results dashboard
- Real/Fake classification display
- Fake probability and classification confidence display
- Optional heatmap display
- Demo mode using simulated results
- Configurable backend API integration

## Supported File Formats

Images: JPG, JPEG, PNG, WEBP

Videos: MP4, WEBM

Audio: MP3, WAV, OGG

Provisional frontend file size limit: 100 MB.

These restrictions must be aligned with the backend.

## Installation

Requirements:
- Node.js compatible with the installed Vite version
- npm

Install dependencies:

    npm install

Create a local environment configuration by copying
.env.example to .env.

Start the development server:

    npm run dev

Open the local URL shown in the terminal.

## Environment Configuration

Demo mode:

    VITE_API_MODE=mock
    VITE_API_BASE_URL=http://localhost:8000

Live backend mode:

    VITE_API_MODE=live
    VITE_API_BASE_URL=http://localhost:8000

Restart the Vite server after changing environment variables.

## Backend Integration

The frontend sends an HTTP POST request to:

    POST /analyze

Request format:

    multipart/form-data

Required form field:

    file

Proposed JSON response:

    {
      "label": "FAKE",
      "fake_probability": 0.86,
      "modality": "image",
      "explanation": "Optional explanation",
      "heatmap_url": null
    }

The fake_probability field is expected to be a number
between 0 and 1.

This API contract is provisional and must be agreed upon
with the backend team.

## Demo Mode

Demo mode uses fixed simulated classification scores:

- Image: 0.86 fake probability
- Video: 0.72 fake probability
- Audio: 0.18 fake probability

These values are not generated by an AI model and are
not actual detection results.

## Build

Run:

    npm run build

The production output is generated inside the dist folder.

## Current Limitations

- Live model inference requires the backend.
- Demo predictions are simulated.
- Heatmaps are displayed only when supplied by the API.
- Client-side validation is not a security boundary.
- Confidence is derived from the classification score and
  is not independently calibrated.
- Backend integration testing remains pending.

## Module Responsibility

Module 1 is responsible for the user-facing interface
and communication with the backend API.

Actual media preprocessing, model inference, multimodal
fusion, and generation of reports or heatmaps belong
to other project modules.
